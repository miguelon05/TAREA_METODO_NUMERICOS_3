Punto fijo, Newton-Raphson y secante con error relativo porcentual menor o igual a 0.01%.

Metodo de punto fijo - Control de temperatura

Se busca la temperatura de equilibrio de una sala de servidores.

T = 18 + 8e^(-0.15T),   T0 = 20

Grafica de convergencia

Tabla de iteraciones

Interpretacion: la temperatura se estabiliza cerca de 18.499 °C, dentro de un rango adecuado para operacion continua.

Convergencia: g'(T) = -1.2e^(-0.15T); alrededor de la raiz su valor absoluto es menor que 1, por eso el metodo converge desde T0 = 20.

Codigo fuente comentado 
function puntoFijo() {
  const g = T => 18 + 8 * Math.exp(-0.15 * T);
  let T = 20;
  const filas = [];

  for (let i = 1; i <= 50; i++) {
    const nuevo = g(T);
    const ea = Math.abs((nuevo - T) / nuevo) * 100;
    filas.push({ i, x: nuevo, fx: nuevo - g(nuevo), ea });
    if (ea <= 0.01) break;
    T = nuevo;
  }
  return filas;
}

Metodo de Newton-Raphson - Sistema de almacenamiento

Se calcula el tiempo positivo de respuesta del sistema.

f(t) = t^3 - 7t - 5 = 0,   t0 = 3

Grafica de convergencia

Tabla de iteraciones

Interpretacion: la raiz positiva indica un tiempo promedio de respuesta de aproximadamente 2.949 ms.

Eleccion inicial: t0 = 3 es conveniente porque f(2) < 0, f(3) > 0 y f'(3) no es cero.

Codigo fuente comentado 
function newtonRaphson() {
  const f = t => t ** 3 - 7 * t - 5;
  const df = t => 3 * t ** 2 - 7;
  let t = 3;
  const filas = [];

  for (let i = 1; i <= 50; i++) {
    const nuevo = t - f(t) / df(t);
    const ea = Math.abs((nuevo - t) / nuevo) * 100;
    filas.push({ i, x: nuevo, fx: f(nuevo), ea });
    if (ea <= 0.01) break;
    t = nuevo;
  }
  return filas;
}

Metodo de la secante - Rendimiento de servidor

Se estima el nivel de carga normalizado que define el punto de operacion.

f(x) = e^(-x) - x^2 + 0.2 = 0,   x0 = 0, x1 = 1

Grafica de convergencia

Tabla de iteraciones

Interpretacion: el servidor alcanza el punto de operacion en x = 0.80454, es decir, cerca del 80.45% de carga normalizada.

Eleccion inicial: se usan x0 = 0 y x1 = 1 porque f(0) > 0 y f(1) < 0; el cambio de signo encierra la raiz.

Codigo fuente comentado 
function secante() {
  const f = x => Math.exp(-x) - x ** 2 + 0.2;
  let x0 = 0;
  let x1 = 1;
  const filas = [];

  for (let i = 1; i <= 50; i++) {
    const x2 = x1 - f(x1) * (x1 - x0) / (f(x1) - f(x0));
    const ea = Math.abs((x2 - x1) / x2) * 100;
    filas.push({ i, x: x2, fx: f(x2), ea });
    if (ea <= 0.01) break;
    x0 = x1;
    x1 = x2;
  }
  return filas;
}

Criterio de parada aplicado: error relativo aproximado menor o igual a 0.01% o maximo de 50 iteraciones.
